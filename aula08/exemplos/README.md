# Exemplos da aula 8 — JavaScript e o DOM

Cada exemplo é uma **pasta** com um documento completo: o `index.html` e, quando há, os arquivos próprios (`js/`, `tokens.css`, fotos). Entre na pasta e clique no arquivo: o GitHub mostra o código na própria página. É o mesmo código dos slides e da apostila.

Cada pasta também abre no navegador, no endereço do GitHub Pages deste repositório: <https://fab-araujo.github.io/2026.2-LPS-BSI-PGM/aula08/exemplos/>. Com o F12 aberto, dá para ver no Console e na aba Elementos o que a captura mostrou.

Estes exemplos são para **ler e mexer**, não para copiar: no seu site vai só o que você digitar.
