# Aula 8 — Introdução ao JavaScript e o primeiro componente

A aula 8 apresenta o JavaScript (história, características e as três formas de pôr código numa página) e o primeiro contato com o React, pelo tutorial do jogo da velha no CodeSandbox: componente, JSX, props, clique e estado.

Duas pastas:

- `react/` — o código de cada passo do tabuleiro e do `Produto` mostrados na aula; para abrir e comparar com o seu. Leia o [`react/README.md`](react/).
- `exemplos/` — os exemplos da **apostila suplementar** (servir o site, módulos, DOM, eventos, busca e filtro, depuração) e, no fim, as três formas de JavaScript. A lista com o título de cada página está em [`exemplos/README.md`](exemplos/).
